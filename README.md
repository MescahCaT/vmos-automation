# VMOS TikTok 自动化管理系统

当前模块的统一用法见 [使用模板](使用模板.md)，可直接运行 `阶段9-脚本开发与集成/use_modules.ps1`；默认只读检查现有测试机，另有配置安装、登录和串联模式。阶段7/8按用户要求暂缓。

批量准备代理与云机名称清单的文本工具见[阶段9文本导入说明](阶段9-脚本开发与集成/文本导入使用说明.md)；它生成创建 JSON 和代理对应表，不会自动提交云机创建。

清单生成后，在项目根目录执行 `python -X utf8 .\创建云机.py`，依次完成创建、绑定SOCKS5及中转、设置国家、时区、语言、GPS、重启回查、联网验证和TikTok安装；已有云机加 `--configure-only`。中转沿用上次配置。代理必须配置完整region，缺失或无效时在创建前停止。APK沿用主配置 `tiktok.apk_path`，创建前校验包名，已安装则跳过上传。地区配置成功后，即使网页探测失败也执行当前云机的本地安装，联网失败仍记为失败并停止后续云机。地区、联网与安装结果分别记录到独立任务目录，全部结束后统一恢复原运行/停机状态。

只执行某一步可使用 `仅创建云机.py`、`设置代理.py`、`设置地区.py`、`安装TK.py`，均支持按名称选择一台或多台，命令见 [独立操作指令](独立操作指令.md)。`python -X utf8 .\创建云机.py --workers 3` 保持创建并完整初始化的含义。

## 📋 项目概述

本项目旨在实现 100+ VMOS 云机的 TikTok 账号批量管理自动化系统，包括云机创建、代理配置、应用安装、账号登录、内容发布等全流程自动化。

## 🎯 核心功能

1. **批量云机管理** - 自动创建、配置、启动 100+ 云机实例
2. **网络代理配置** - 指定云机配置代理并验证实际出口，批量与链式分流待集成
3. **TikTok 自动化** - 自动安装、登录、发布内容
4. **账号信息采集** - 定时采集粉丝数、橱窗状态等数据
5. **智能监控告警** - 实时监控云机状态、代理状态、账号状态

## 🚀 快速开始

### 环境要求

- Python 3.8+
- VMOS Edge 主机（CBS 1.1.1.10+）
- 稳定的代理服务器
- TikTok APK 文件

### 安装依赖

```bash
python -m pip install requests
```

### 配置文件

首次从仓库下载后，复制配置示例并按自己的环境填写：

```powershell
Copy-Item .\配置文件\config.example.json .\配置文件\config.json
Copy-Item .\配置文件\proxy_list.example.json .\配置文件\proxy_list.json
Copy-Item .\配置文件\account_list.example.json .\配置文件\account_list.json
Copy-Item .\阶段9-脚本开发与集成\batch_create.template.json .\阶段9-脚本开发与集成\batch10_create.example.json
```

示例只含占位值。实际配置、账号与代理信息、运行数据、日志、截图、备份、APK 和第三方可执行文件由 `.gitignore` 排除，需在本地准备。文档中的验收记录及运行结果也保留在本地，仓库内的相关链接可能无法打开。使用 `use_modules.ps1` 时请显式传入自己的 `-DbId`、`-ProxyId` 和 `-Email`。

当前模块读取 `配置文件/config.json`：主机 `192.168.110.35:18182`，目标1台，已填镜像、机型和APK。实际代理与账号分别在 `proxy_list.json` 和 `account_list.json`。登录支持密码或网页验证码，取码不使用邮箱密码；密码通过环境变量提供。当前已登录测试机无需重新输入密码。

## 🔧 技术栈

- **语言**: Python 3.8+
- **HTTP**: requests
- **数据处理**: pandas, openpyxl
- **配置**: JSON（阶段1），旧 YAML 规划待整合
- **OCR**: pytesseract (可选)
- **邮箱验证码**: 网页 API（GET username=邮箱）

## ⚠️ 注意事项

1. **安全性**: VMOS API 仅适用于可信局域网，不要暴露到公网
2. **风控**: TikTok 有严格的设备指纹和行为检测，需注意账号安全
3. **人机验证**: 自动登录可能遇到 Captcha，需要人工介入或打码平台
4. **资源**: 100+ 云机对主机性能要求较高，建议配置 32GB+ 内存
