# 代码开发规范

## 📋 总体原则

遵循 **全局工程规范**（CLAUDE.md）：
- 轻量化输出，降低维护成本
- 分层清晰，函数单一职责
- 只保留生产必需逻辑
- 注释简洁明确

## 🏗️ 项目结构规范

```
project/
├── src/                  # 源代码
│   ├── core/            # 核心模块
│   ├── managers/        # 管理器
│   ├── utils/           # 工具函数
│   └── config/          # 配置管理
├── tests/               # 测试代码
├── logs/                # 日志文件
├── data/                # 数据文件
├── config/              # 配置文件
└── docs/                # 文档
```

## 📝 命名规范

### 文件命名
- Python 文件：小写+下划线 `vmos_client.py`
- 配置文件：小写+下划线 `config.yaml`
- 日志文件：小写+下划线+日期 `automation_20250115.log`

### 变量命名
- 变量/函数：小写+下划线 `device_manager`
- 类名：大驼峰 `VMOSClient`
- 常量：大写+下划线 `MAX_RETRY_COUNT`
- 私有变量/方法：前缀下划线 `_internal_method`

### 示例
```python
# 常量
MAX_DEVICES = 100
API_TIMEOUT = 30

# 类
class DeviceManager:
    pass

# 函数
def create_device(config):
    pass

# 变量
device_list = []
proxy_config = {}
```

## 📦 模块设计规范

### 单一职责
每个模块只负责一个功能领域：
```python
# ✅ 好的设计
# vmos_client.py - 只负责 API 调用
# device_manager.py - 只负责设备管理
# proxy_manager.py - 只负责代理管理

# ❌ 不好的设计
# utils.py - 包含所有功能的大杂烩
```

### 分层清晰
```
表现层 (main.py)
    ↓
业务层 (managers/)
    ↓
核心层 (core/)
    ↓
工具层 (utils/)
```

## 💬 注释规范

### 模块注释
```python

模块名称：VMOS API 客户端
功能：封装 VMOS HTTP API 调用
作者：XXX
创建：2025-01-15

```

### 类注释
```python
class VMOSClient:
    """VMOS API 客户端
    
    封装 VMOS Container API 和 Control API 调用
    """
```

### 函数注释
```python
def create_device(config: dict) -> dict:
    """创建云机实例
    
    Args:
        config: 设备配置字典
            - user_name: 设备名称
            - image_repository: 镜像名
            
    Returns:
        包含 db_id 的字典
    """
```

### 关键逻辑注释
```python
# 等待 ROM 就绪，最多重试 10 次
for i in range(10):
```

### 禁止的注释
```python
# ❌ 不要写这种没用的注释

device_list = []

# 循环遍历
for device in devices:
    pass
```

## 🔧 函数设计规范

### 函数长度
- 单个函数不超过 50 行
- 超过则拆分为多个子函数

### 参数数量
- 建议不超过 5 个参数
- 超过则使用字典或配置对象

### 返回值
- 统一返回类型
- 使用类型注解

```python
# ✅ 好的设计
def create_device(config: dict) -> dict:
    """返回统一格式"""
    return {
        'success': True,
        'db_id': 'EDGE001',
        'message': '创建成功'
    }

# ❌ 不好的设计
def create_device(config):
    """返回值不统一"""
    if success:
        return db_id  # 字符串
    else:
        return None   # None
```

## 🚨 错误处理规范

### 异常捕获
```python
# ✅ 捕获具体异常
try:
    response = requests.get(url, timeout=10)
    response.raise_for_status()
except requests.Timeout:
    logger.error("请求超时")
except requests.HTTPError as e:
    logger.error(f"HTTP 错误: {e}")

# ❌ 不要捕获所有异常
try:
    do_something()
except:
    pass
```

### 标记 FIXME
```python
# 需要后续处理的点标记 FIXME
def login(account):
    # #FIXME 人机验证需要优化
    if detect_captcha():
        return manual_intervention()
```

## 📊 日志规范

### 日志级别
- `DEBUG`: 调试信息
- `INFO`: 一般信息
- `WARNING`: 警告信息
- `ERROR`: 错误信息
- `CRITICAL`: 严重错误

### 日志格式
```python
import logging

logger = logging.getLogger(__name__)

# 使用
logger.info("开始创建云机")
logger.warning("代理连接不稳定")
logger.error("创建失败: %s", error_msg)
logger.debug("配置详情: %s", config)
```

### 日志内容
```python
# ✅ 好的日志
logger.info("创建云机: user_name=TK-001, db_id=EDGE001")
logger.error("API 调用失败: url=/create, code=500, msg=服务器错误")

# ❌ 不好的日志
logger.info("成功")
logger.error("错误")
```

## 📊 性能规范

### 避免重复计算
```python
# ✅ 缓存结果
device_list = get_devices()
count = len(device_list)
for device in device_list:
    process(device, count)

# ❌ 重复调用
for device in get_devices():
    process(device, len(get_devices()))
```

### 批量操作
```python
# ✅ 批量处理
batch_create_devices(device_configs)

# ❌ 逐个处理
for config in device_configs:
    create_device(config)
```

## 🎯 代码示例

### 标准模块结构
```python
"""
模块名称：设备管理器
功能：云机创建、启动、状态查询
"""

import logging
from typing import List, Dict
from .vmos_client import VMOSClient

logger = logging.getLogger(__name__)


class DeviceManager:
    """云机管理器"""
    
    def __init__(self, client: VMOSClient):
        self.client = client
        self.devices = []
    
    def create(self, config: dict) -> dict:
        """创建单个云机
        
        Args:
            config: 设备配置
            
        Returns:
            创建结果字典
        """
        logger.info(f"创建云机: {config.get('user_name')}")
        
        try:
            result = self.client.create_device(config)
            if result['code'] == 200:
                logger.info(f"创建成功: {result['data']['db_id']}")
                return {'success': True, 'db_id': result['data']['db_id']}
            else:
                logger.error(f"创建失败: {result['msg']}")
                return {'success': False, 'error': result['msg']}
        except Exception as e:
            logger.error(f"创建异常: {e}", exc_info=True)
            return {'success': False, 'error': str(e)}
    
    def batch_create(self, count: int, base_config: dict) -> List[dict]:
        """批量创建云机
        
        Args:
            count: 创建数量
            base_config: 基础配置
            
        Returns:
            创建结果列表
        """
        results = []
        for i in range(count):
            config = base_config.copy()
            config['user_name'] = f"TK-{i+1:03d}"
            result = self.create(config)
            results.append(result)
        
        return results
```
