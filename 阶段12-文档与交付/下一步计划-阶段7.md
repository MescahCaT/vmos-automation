# 下一步计划：阶段7内容发布

更新时间：2026-10-23。

## 已完成：阶段7.1素材上传

根目录入口 `上传素材.py` 提供素材池分配和 Tab 任务清单两种模式。支持 MP4、PNG、JPG、JPEG；素材文件夹只读取首层；素材池在云机间不重复分配；任务路径支持单个文件或文件夹。上传通过单台 Control API 的 `file/import`，显式关闭媒体扫描。仅在接口返回目标路径和文件大小匹配后归档源文件至 `已上传`。详见 [阶段7 README](../阶段7-素材上传与内容发布/README.md)。

离线测试覆盖分配唯一性、素材不足、任务文件夹过滤、归档重名保护及 `scan=false` 请求。未连接真实云机，未进行云端上传验证。

## 后续：TikTok编辑与发布

发布功能尚未实现。实现前需明确并单独确认以下范围：

- 首轮要停在素材预览、保存草稿，还是进行一次真实发布。
- 文案来源及各素材与文案的对应关系。
- 是否允许设置封面、音乐、可见范围或其他发布选项。
- 发布后的成功判定方式，以及超时或结果不明时只回查、不重复提交的处理方式。

开始发布工作前先用一台已登录云机和用户提供的测试素材验证页面流程；正式发布须在账号、素材、文案和可见范围逐项确认后执行。上传成功、接口 HTTP 200 或点击发布按钮均不能单独作为发布成功证据。

阶段8账号监控和阶段9统一编排仍按项目交接文档中的计划执行；阶段7上传成功不代表发布流程或批量调度已验收。
