# VMOS 自动化系统配置说明

## 2026-10-13 当前可运行配置

阶段1运行配置已落地为 JSON，直接由 Python 标准库读取：

- `config.json`：VMOS `192.168.110.35:18182`，目标 `device.count=1`，Android 15 镜像，`adiID=1039`（实际为 OnePlus 12），TikTok APK、本机 aapt 路径及网页取码端点。
- `proxy_list.json`：用户提供的实际 SOCKS5 代理，结构为 `id/protocol/host/port/username/password/enabled`；仅此配置保存认证信息。
- `account_list.json`：三个启用的测试邮箱 `account001@example.com`、`account002@example.com`、`account003@example.com`，登录方式 `email_code`；对应 `username` 用于登录后身份核验，不保存 TikTok 密码或邮箱密码。

网页取码使用主配置中的端点，HTTP GET 参数为 `username=邮箱`。不需要邮箱密码或 IMAP。阶段6支持纯文本六位数字及 JSON 响应，保留纯文本代码的前导零；登录提交前读取基线，只接受之后变化的新码。报告不保存验证码。

所有资源路径相对项目根目录。检查结果输出到 `数据/environment_check.json`、`数据/vmos_info.json` 和 `数据/device_mapping.json`。设备映射引用 `proxy_id`，不放代理密码。

运行：`python .\阶段1-环境准备与配置\check_vmos_connection.py`。

这些配置目前服务于阶段1、阶段3代理入口、阶段5统一安装入口和阶段6单台登录入口，其他旧脚本尚未统一迁移；阶段2仍读取它自己的设备 JSON。阶段3必须指定单台 `--db-id` 与 `--proxy-id`，成功验证后更新 `数据/device_mapping.json` 的代理绑定；云机实测出口为 `198.65.101.179`，报告位于 `阶段3-网络代理配置/proxy_status.json`。阶段6要求明确 `--db-id` 和 `--email`，只有本人资料页与本地用户名一致才更新账号绑定；三个邮箱提交均失败，目前未验收。下方原有 YAML、IMAP、100 台等示例属于历史规划，并非当前已实现配置；以这里及对应阶段 README 为准。

## ⚙️ 主配置文件：config.yaml

### 完整配置示例
```yaml
# ==================== VMOS 主机配置 ====================
vmos:
  host_ip: "192.168.100.24"
  port: 18182
  timeout: 30

# ==================== 云机配置 ====================
device:
  # 创建数量
  count: 100
  
  # 命名规则
  name_prefix: "TK"
  name_format: "{prefix}-{index:03d}"  # TK-001, TK-002...
  
  # 镜像配置
  image_repository: "vcloud_android13_edge_20250925011125"
  
  # 分辨率
  resolution:
    width: 1080
    height: 1920
    dpi: 420
    fps: 60
  
  # 网络模式
  network_mode: "bridge"  # bridge 或 macvlan
  
  # 创建后是否立即启动
  auto_start: true
  
  # GMS 配置
  gms_disabled: false
  gms_upgrade_enable: false
  
  # 端口分配范围
  port_range:
    video_start: 25000
    audio_start: 27000
    control_start: 29000
    adb_start: 31000

# ==================== 代理配置 ====================
proxy:
  # 是否启用代理
  enabled: true
  
  # 代理配置文件路径
  config_file: "配置文件/proxy_list.yaml"
  
  # 代理分配策略
  assignment: "sequential"  # sequential: 顺序分配, random: 随机分配
  
  # 代理验证
  verify: true
  verify_timeout: 10

# ==================== TikTok 配置 ====================
tiktok:
  # APK 配置
  apk:
    source: "local"  # local: 本地文件, url: URL下载
    path: "/path/to/tiktok.apk"
    url: ""  # source=url 时使用
  
  # 包名
  package_name: "com.zhiliaoapp.musically"
  
  # 账号配置文件路径
  account_file: "配置文件/account_list.yaml"
  
  # 登录配置
  login:
    max_attempts: 3
    retry_delay: 60
    captcha_handler: "manual"  # manual: 手动, api: 打码平台
  
  # 发布配置
  publish:
    caption_template: "配置文件/captions.yaml"
    auto_hashtag: true

# ==================== 系统配置 ====================
system:
  # GPS 定位
  location:
    auto_match: true  # 根据代理地区自动匹配
    fallback:
      country: "US"
      lat: 40.7128
      lon: -74.0060
      timezone: "America/New_York"
  
  # 语言配置
  locale:
    auto_match: true
    fallback:
      language: "en"
      country: "US"

# ==================== 日志配置 ====================
logging:
  level: "INFO"  # DEBUG, INFO, WARNING, ERROR, CRITICAL
  format: "%(asctime)s - %(name)s - %(levelname)s - %(message)s"
  
  # 文件日志
  file:
    enabled: true
    path: "日志/automation.log"
    max_bytes: 10485760  # 10MB
    backup_count: 5
  
  # 控制台日志
  console:
    enabled: true
    level: "INFO"

# ==================== 重试配置 ====================
retry:
  max_attempts: 3
  initial_delay: 5
  backoff_factor: 2
  max_delay: 60

# ==================== 监控配置 ====================
monitor:
  enabled: true
  interval: 300  # 5分钟
  
  # 告警阈值
  alert:
    device_offline_threshold: 5  # 分钟
    proxy_failed_threshold: 3    # 次数
    cpu_threshold: 90            # 百分比
    memory_threshold: 90

# ==================== 数据采集配置 ====================
collection:
  enabled: true
  interval: 3600  # 1小时
  
  # 输出配置
  output:
    format: "xlsx"  # xlsx, csv, json
    path: "数据/account_data.xlsx"

# ==================== 备份配置 ====================
backup:
  enabled: true
  schedule: "0 2 * * *"  # 每天凌晨2点
  path: "/backup/vmos_automation"
  retention_days: 30
```

## 🎯 配置加载示例

```python
import yaml
import os
from dotenv import load_dotenv

# 加载环境变量
load_dotenv()

# 加载主配置
with open('配置文件/config.yaml', 'r', encoding='utf-8') as f:
    config = yaml.safe_load(f)

# 加载代理配置
with open('配置文件/proxy_list.yaml', 'r', encoding='utf-8') as f:
    proxies = yaml.safe_load(f)

# 加载账号配置
with open('配置文件/account_list.yaml', 'r', encoding='utf-8') as f:
    accounts = yaml.safe_load(f)

# 使用环境变量覆盖敏感配置
config['vmos']['host_ip'] = os.getenv('VMOS_HOST_IP', config['vmos']['host_ip'])
```

## 📝 配置验证

```python
def validate_config(config):
    """验证配置完整性"""
    
    required_keys = [
        'vmos.host_ip',
        'device.count',
        'device.image_repository',
        'tiktok.apk.path'
    ]
    
    for key in required_keys:
        keys = key.split('.')
        value = config
        for k in keys:
            if k not in value:
                raise ValueError(f"缺少必需配置: {key}")
            value = value[k]
    
    print("✅ 配置验证通过")
```
